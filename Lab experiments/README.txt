COURSE OUTCOME 1 - PYTHON PRACTICAL EXPERIMENTS

This folder contains 20 separate Python programs matching the 20 experiments
in the provided Course Outcome 1 practical list.

HOW TO RUN
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install core dependencies:
   python -m pip install numpy pandas matplotlib scikit-learn torch
4. For experiments 7-20, install Transformers:
   python -m pip install transformers
5. Run a file, for example:
   python experiment01_matplotlib_line_graph.py

IMPORTANT
- Experiments 7-20 download pretrained models from Hugging Face on first run.
  An internet connection is required for the first download.
- Model downloads can be large and take time.
- Sample outputs can vary by installed library version or model output.
- Experiment 1 opens a graph window; close the window to finish the program.
- Run each experiment on your computer and show the actual output to faculty.
